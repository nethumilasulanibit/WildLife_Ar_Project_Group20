# Wildlife Discovery Lab

A small AR wildlife scene made with HTML, JavaScript, A-Frame and AR.js.

## How to use

Open the website, allow the camera and point it at the Hiro marker.

- Tap the pink ball to change its colour.
- Tap the green tube to start or stop bouncing.
- You can also use the buttons on the screen.

Use `preview.html` to try the scene without a camera.
